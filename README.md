# Face Recognition Attendance System

A Python-based application that automates attendance using face recognition.

## Features
- Face detection using OpenCV
- Real-time attendance marking
- GUI-based interface using Tkinter
- Attendance record management

## Technologies Used
- Python
- OpenCV
- NumPy
- Pandas
- Tkinter

## How It Works
1. Capture face images
2. Train the model
3. Recognize faces using webcam
4. Automatically mark attendance

## Outcome
This project demonstrates practical implementation of computer vision and automation in real-world scenarios.
